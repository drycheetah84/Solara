# event-build-quality

> User feedback on EREBUS event map building — must be event-scale, textured, dressed; never show untextured/blocky previews
>
> Type: feedback. Written by Claude during sessions with the project owner ("the user" = the owner). Paths under `C:\Users\drych\` are on the owner's PC. Verify status lines against the code before acting.

For the EREBUS PROTOCOL live event map the user wants a Fortnite-live-event-style FACILITY (hallways, walls, rooms the
players move through while the show plays) — NOT an arena/game-mode set, and NOT a small boxy MVP.
2026-11-03 they rejected v1 (16 m rooms, 4 m corridors, 40 m chamber, untextured white preview): "looks like a MVP…
not textures… so small that's shit for a event".

**Why:** a live event is a spectacle; scale, real A2 materials and set dressing are the point.

**How to apply:** build at spectacle scale (main space ~100 m+, tall, giant windows/superstructure set pieces, 8 m
halls), dress every space (props, accent lights, signage, screens, moody contrast, not evenly lit white), and only show
previews that use the real exported A2 textures (stand-in imports must get their textures wired). Don't present a
blockout as the result; check renders critically before sending. Related: [erebus-protocol-event](erebus-protocol-event.md).
