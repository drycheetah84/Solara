**Evidence:** BADLEN always len=0x0064006D ("md" UTF-16), src=0x006F006300650053 ("Seco") — i.e. the reader reads string TEXT as an FString length+ptr → cursor is misaligned. **Ruled out:** tier-1 count-clamp at struct+0x38 — the count is a 6/14-bit field so it can never exceed 0x10000; clamp never fires. 22284 string-match for the analog gave a FALSE POSITIVE (sub_465E0E0 is an ImGui "DrawVariableTable" debug fn, not the reader).
